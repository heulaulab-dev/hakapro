# Indonesian public sources for a market data crawler

Date: 2026-10-21  
Scope: whether HAKAPRO can crawl Indonesian public sources for stock OHLCV and fundamentals without buying a market-data license. Reviewed official IDX, OJK, BPS/Satu Data Indonesia, and Bank Indonesia material. This is a source and terms review, not legal advice.

## Decision

**No qualifying free source was found for an automated, production crawler that supplies daily OHLCV for all IDX-listed equities and permits storing and serving those rows in HAKAPRO.**

The official IDX stock-summary page displays broad market rows and OHLC-like fields, but IDX's current website terms explicitly say web scraping/crawling is not permitted, and prohibit commercial use or distribution of website data without prior written permission. The fact that the table is visible and has a download button does not override those restrictions. Do not build a crawler against this page or its underlying requests without written permission.

OJK and BPS publish useful public financial statistics and historic stock-market files, but the reviewed public material does not establish an open license for automated harvesting and commercial redistribution. Neither provides a verified current, per-ticker daily OHLCV feed. BI provides a documented public exchange-rate web service, which could add macro context, but it is not equity market data and its service page does not by itself grant HAKAPRO a redistribution license.

For HAKAPRO's existing full-market EOD feature, there is no evidence-backed “free crawl it” replacement. Keep that feature marked unavailable/partial until a provider or rights holder grants written permission, or narrow the product to user-supplied data and sources whose specific terms expressly allow this use.

## Specific answers

### Is all-IDX-stock OHLCV publicly visible?

IDX's Ringkasan Saham page displays a current-date, all-stock table with open/high/low/close and volume fields (along with value and frequency); the result currently showed 963 rows. This establishes **visible table coverage for a date**, not a licensed historical dataset or authorized crawler interface. Under IDX's published terms, HAKAPRO must not scrape/crawl that page. The data-services FAQ distinguishes licensed IDX EOD delivery (including controlled licensee access) from the website view, while the terms expressly limit website data use.

Thus the precise answer is: **the fields appear publicly viewable for broad daily coverage, but no lawful automated/reusable all-stock OHLCV source without permission or license was verified.** Do not derive a technical endpoint from the site's frontend or call undocumented/private endpoints; even a discoverable endpoint would not change the terms.

### What can the crawler ingest without a paid license?

This review cannot affirm any market-data dataset as safe for HAKAPRO's production commercial crawler solely because it is publicly accessible. Potential next steps that do not assume permission:

1. Ask IDX in writing for a no-cost/non-commercial/developer grant or an explicit permission/API for the limited HAKAPRO use case. If refused, ask which product is the lowest-cost route and whether derived indicators can be shown to end users.
2. Ask OJK for the Portal Data API/export documentation and terms covering scheduled reads, database storage, transformed indicators, and user display. Until written terms are clear, keep ingestion disabled.
3. Ask BPS/Satu Data Indonesia for the license applicable to the named 1994–2022 dataset and whether each resource file may be automatically retrieved and used commercially. Treat this only as potential historic data, not current EOD.
4. For issuer filings, make a per-source register of allowed terms and use company-hosted reports only where the issuer's terms or written permission expressly cover automated retrieval and intended reuse. Keep source links and document dates; do not republish full documents by default.
5. Add BI exchange-rate data only as a separate macro series and only after confirming reuse conditions; it does not resolve stock-price coverage.

Until one of those rights paths is confirmed, the engine may continue to process operator-supplied files or explicitly authorized sources, but it must not silently scrape IDX/OJK pages or imply that publicly viewable means commercially reusable.

## Recommendation for HAKAPRO

Keep `yahoo-chart` blocked and do not replace it with a crawler pointed at IDX's site. Record `IDX web EOD` as **visible but crawling prohibited under published terms**. Record OJK, BPS, and BI as **public sources with reuse terms not established by this review** (BI is macro-only). Disable market-price coverage claims until IDX or a data owner grants written rights or a provider with explicit free-use terms is verified. Preserve the existing source adapter and database contracts so an authorized feed or permitted operator upload can be added without changing the app's data API.
